# حساب‌یار — نسخه ابری

اپلیکیشن فارسی و راست‌چین برای ثبت بدهی و اقساط، پرداخت‌ها، درآمد، هزینه و هدف‌های پس‌انداز. داده‌ها با حساب کاربری Supabase بین آیفون، مک و مرورگرهای دیگر همگام می‌شوند.

## راه‌اندازی محلی
1. Node.js نسخه 18 یا جدیدتر نصب باشد.
2. در Supabase یک پروژه بساز.
3. فایل `supabase/schema.sql` را کامل در SQL Editor پروژه اجرا کن.
4. از Project Settings → API، Project URL و کلید عمومی `anon` یا `publishable` را بردار.
5. `.env.example` را به `.env` تغییر نام بده و دو مقدار را جایگزین کن.
6. در ترمینال پوشه پروژه:
   ```bash
   npm install
   npm run dev
   ```
7. برای نسخه نهایی:
   ```bash
   npm run build
   ```
   خروجی آماده انتشار در پوشه `dist` قرار می‌گیرد.

## انتشار و نصب
پوشه پروژه را می‌توان روی Vercel یا Netlify منتشر کرد. متغیرهای محیطی `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` را در تنظیمات همان سرویس نیز تعریف کن. سپس نشانی سایت را در Safari آیفون باز کن و از Share → Add to Home Screen استفاده کن.

## امنیت
- فقط کلید عمومی Supabase (anon/publishable) در فرانت‌اند قرار می‌گیرد.
- هر جدول دارای `user_id` و سیاست RLS است؛ کاربر فقط ردیف‌های خودش را می‌خواند و تغییر می‌دهد.
- هرگز `service_role` key را در `.env` فرانت‌اند، مخزن عمومی یا چت قرار نده.
- برای پروژه مالی واقعی، تأیید ایمیل، رمز قوی و پشتیبان‌گیری دوره‌ای را فعال نگه دار.

## نکته‌های نسخه فعلی
- تاریخ ورودی فعلاً با کنترل تاریخ مرورگر است و ممکن است میلادی نمایش داده شود؛ تبدیل و نمایش کامل تقویم شمسی در مرحله بعد اضافه می‌شود.
- مبلغ‌ها در تومان هستند.
- ثبت پرداخت، تاریخچه پرداخت را در `debt_payments` نگه می‌دارد و مبلغ پرداخت‌شده بدهی را به‌روزرسانی می‌کند.
- برای جلوگیری از ثبت اشتباه، مبلغ پرداخت نمی‌تواند از مانده بدهی بیشتر باشد.
